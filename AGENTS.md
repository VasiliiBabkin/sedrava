# Sedrava contributor and agent instructions

Before planning or implementing any change, read [the normative Sedrava declaration](docs/DECLARATION.ru.md) and [the contribution rules](CONTRIBUTING.md). The governing principle is **«Описал — получил» / Describe the application; get the application**.

Apply the declaration's Architecture Gate. Prefer a declarative domain model and a single source of truth over mandatory manual HTTP/SQL/UI wiring. Preserve deterministic semantics, explicit security and data integrity. Compare before/after on a real application, or supply a measurable infrastructure improvement. Do not claim planned syntax is implemented. Do not change the declaration without the owner's explicit agreement. Existing release evidence, compatibility and safety gates remain in force.
