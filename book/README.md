## Как ведём учебники

Два маршрута, единая проверяемая база примеров. Тексты в Markdown; примеры хранятся рядом. В главе указываются проверенная версия, точные команды, ожидаемый результат и ограничения. Новые конструкции сначала проходят приёмку языка, затем публикуются в учебнике соответствующего выпуска. Ссылки на документацию относятся к той же версии. Объяснения и задания не требуют будущих возможностей.

Сборка книги в PDF/EPUB и публикация отдельного раздела сайта запланированы после наполнения, не считаются выполненными. Лицензия репозитория применяется согласно LICENSE.

Проверка примеров: SEDRAVA_NATIVE_BIN=/absolute/path/to/sedrava python3 -B scripts/verify_book.py из корня репозитория. Python — только инструмент тестирования книги, не зависимость приложения.
