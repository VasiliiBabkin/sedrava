# Глава 1. Что значит описать приложение

Проверенная версия: Sedrava 0.12.0-alpha.4, Linux x86-64 GNU.

Программирование начинается не с выбора кнопок и библиотек, а с понимания задачи. Представим счётчик: он запоминает число, увеличивает его, уменьшает и сбрасывает. Число не должно стать отрицательным. Именно это и нужно сообщить компьютеру.

Sedrava позволяет описать состояние, допустимые действия, правила и экран. Компилятор определяет реализацию в пределах поддерживаемых конструкций. Это не язык произвольных запросов на русском: ключевые слова и правила записи имеют определённый синтаксис.

## Подготовка

Установите проверенный комплект по [инструкции](../../docs/PLATFORM_RELEASE_A39.ru.md). Команда sedrava --version должна показать sedrava 0.12.0-alpha.4 (Rust alpha). Для работы по главе скопируйте файл [counter.sdr](../examples/counter/counter.sdr) в новый каталог. Не нужны Python, JavaScript или Rust для исполнения готовым CLI.

~~~sedrava
app "Sedrava Counter"
state count = 0
action increment: count = count + 1
action decrement: count = count - 1
action reset: count = 0
rule count >= 0
test increment: increment, increment -> count == 2
test reset: increment, reset -> count == 0
screen main:
    text "Sedrava Counter"
    value count
    button "Add" -> increment
    button "Subtract" -> decrement
    button "Reset" -> reset
~~~

Первая строка задаёт имя приложения. state вводит число count с начальным значением 0. action определяет изменение состояния; после двоеточия указано, что именно изменяется. rule — обязательное правило. test описывает проверяемый сценарий. screen задаёт экран и связывает кнопки с действиями. Отступы определяют принадлежность строк экрану.

## Проверяем

~~~sh
sedrava check counter.sdr
sedrava test counter.sdr
sedrava run counter.sdr increment increment
sedrava run counter.sdr increment decrement
~~~

В третьей команде ожидается count = 2, в четвёртой — count = 0. Команда run начинает с начального состояния, если не указан отдельный механизм сохранения.

~~~sh
sedrava run counter.sdr decrement
~~~

Уменьшение от нуля нарушает правило: CLI возвращает ошибку. Это важнее красивого экрана: недопустимое состояние не должно считаться успешным.

## Получаем веб-приложение

~~~sh
sedrava build web counter.sdr --output counter.html
~~~

Откройте полученный HTML в браузере. Это автономный пример, без БД и сервера. Сгенерированный код можно изучить, но для изменения правил следует редактировать counter.sdr и собирать в новый выходной файл. Android требует отдельной сборочной среды; её пока не используем.

## Задание

Добавьте действие, увеличивающее число на 5, и кнопку для него. Напишите test, проверяющий результат двух таких действий. Проверьте результат через CLI. Не меняйте правило count >= 0.

Следующая глава показывает другой тип задачи: приложение с сохраняемыми записями.
