# A5.10a — стековый исполнитель функционального IR

`examples/self_host/function_vm_a510a.sdr` is written in Sedrava. Input is explicit textual IR, not general Sedrava source: `fn NAME argc locals`, one instruction per line, `end`; entry `main` argc 0. Supports const, load/store local slot, add/sub/mul, eq/lt (int 0/1), call, return, jump/jz to 1-based function-relative instruction. Function names resolve to numeric IDs before execution. Forward and recursive calls supported. Stack frames have isolated slots, caller operand floor, checked initialized reads, exact return shape, return PC. Checked i32 arithmetic; literal range -2147483647..2147483647, no implicit casts, boolean/int distinction not yet modeled. Bounds: source 2048 scalars, up to 100 lines/instructions, 16 functions, 8 locals and max 8 frames, 64 operand slots, 256 executed instructions. Invalid IR or budget/overflow aborts via runtime requirements; no typed diagnostic API. Not yet connected to A5.9b parser/lowering, no source function body compiler, full lexical scopes or production backend.

VDS: 4 valid programs (incl. factorial 5=120, peak 6 frames), 9 invalid/limit cases and 2 execution guards PASS. `scripts/verify_selfhost_function_vm_a510a.py`.
