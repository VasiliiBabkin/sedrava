# FAQ

**What is Sedrava?** A declarative language and Rust compiler/runtime for small apps, websites and bounded local services.

**What do I install?** The current alpha executable sedrava. [Downloads and installation](DISTRIBUTION_NATIVE.ru.md).

**Can I use it in production?** Not yet. Read [security](SECURITY.md) and [known limitations](KNOWN_LIMITATIONS.md).

**Is SedravaSQL a full replacement for SQLite/PostgreSQL?** No. It is an experimental independent SQL engine and separate managed SQLite interface. B25 is not yet its SQL backend.

**Where are previous releases?** [History](HISTORY.md).
