# Sedrava 0.12.0a1 — заметки к экспериментальной альфе

**Исходники кандидата, ещё не опубликованного.** Последняя подтверждённая опубликованная версия — [0.10.0](https://github.com/VasiliiBabkin/sedrava/releases/tag/v0.10.0). Подготовка 0.11.0rc1 идёт отдельно в [PR #42](https://github.com/VasiliiBabkin/sedrava/pull/42). Тег `v0.12.0a1` и пакет PyPI не объявляются существующими.

## Реализовано в исходном коде

- `module company.name`, явный `export`, `import "file.sdr" as alias` и обращения `alias.Symbol`.
- Внутренние объявления защищены от внешнего обращения; одинаковые названия независимых модулей не конфликтуют.
- Существующий плоский импорт сохраняется. Новые пространства имён пока преобразуются на лексическом этапе, а не представлены полноценной таблицей символов типизированного IR.
- Для типовых ошибок после разворачивания вложенных импортов сохраняются исходный файл и строка. Полного сопоставления всех столбцов ещё нет.
- Локальные библиотеки из `vendor/` описываются в `sedrava.toml` с точными версиями и фиксируются в `sedrava.lock` с SHA-256.
- Команды `sedrava lock` и `sedrava verify` проверяют целостность и ограничения зависимостей; компилятор проверяет lockfile, если присутствует файл проекта.

## Не реализовано

Сетевой реестр пакетов, автоматическая загрузка, разрешение диапазонов версий, квалифицированный импорт из пакетов, стабильный ABI, доверенный сервер, SQLite/PostgreSQL и аутентификация. Хеш пакета сам по себе не гарантирует безопасность его кода.

## Условия выпуска

Эта альфа основана на ещё не объединённой экспериментальной базе 0.11. До публичной публикации нужно согласовать её с проверенной версией 0.11, завершить испытания точного коммита и отдельно утвердить неизменяемую сборку.
