# A23b — постраничный каталог и заказы

На базе A23a (7c17ce1) добавлены три маршрута без изменений Rust runtime или формата NativeLog:

- POST /products-page {"after":""}: SELECT с id > ?, ORDER BY id, LIMIT 26;
- POST /orders-page {"after":""}: аналогичный LEFT JOIN с Orders.id > ?;
- POST /product-count {}: COUNT(*) AS total.

Пустой cursor начинает список, непустой продолжает строго после указанного ключа. `require after length 0 128`; это лексикографическая граница, не обязательно существующий ключ. 26-я строка — признак продолжения; UI показывает 25 строк и сохраняет историю cursors для кнопки назад. Каталог и заказы имеют независимые cursors. После logout они сбрасываются. При неопределённом результате write навигация заблокирована до завершения повтора. Общий счётчик товаров больше не является счётчиком строк страницы. ID заказа может ссылаться на товар вне текущей страницы, FK проверяется сервером. Прежние /products и /orders сохраняются (старый default limit 100) для обратной совместимости. API по-прежнему авторизован, только loopback.

## Ограничения

Нет snapshot между HTTP запросами, при параллельной записи состав страниц может измениться; счётчик/список не атомарный отчёт. Нет OFFSET, произвольного page-size или поиска номера страницы, нет постоянного cursor после reload. `JOIN` всё ещё сканирует ограниченные входные наборы (MAX_SCAN 4096, join candidate limit 16384), поэтому это не доказательство масштабируемого дискового доступа. Данные до A23a могли содержать другие ключи. Размеры запросов/ответов, лимиты NativeLog и ограничения A22 остаются. Не публичный production-сервер.
