# Sedrava 0.11.0 — заметки к стабильному выпуску

**Пока не опубликована.** Действующая стабильная версия — [0.10.0](https://github.com/VasiliiBabkin/sedrava/releases/tag/v0.10.0) ([PyPI](https://pypi.org/project/sedrava/0.10.0/)). Экспериментальная [0.11.0rc1](https://github.com/VasiliiBabkin/sedrava/releases/tag/v0.11.0rc1) уже доступна на [PyPI](https://pypi.org/project/sedrava/0.11.0rc1/). Ветка `release/011-stable-preparation` содержит *исходники кандидата*, а не выпущенный пакет.

## Возможности

- Адаптивные многостраничные сайты: `sedrava build site`, проверяемые локальные ресурсы, переиспользуемые типизированные компоненты.
- Интерактивные WebApp: `sedrava build webapp`, типизированное состояние, действия, чистые функции, коллекции, маршруты, формы, диалоги и таблицы.
- Ограниченный HTTP-клиент GET/POST/PUT/PATCH/DELETE с проверкой схем; сервер предоставляется отдельно.
- Четыре примера: сайт, задачи, каталог и CRM; сохранены старые `app`, Web и Android.
- Версия `0.11.0`, Android versionCode `11002` (у опубликованного кандидата — 11001).

## Ограничения и публикация

Нет встроенного доверенного сервера, SQLite/PostgreSQL, авторизации и разграничения прав, автоматических миграций, пространств имён и пакетов 0.12. Физические Android-устройства и откат промышленного APK не сертифицированы.

Нужны итоговые проверки Python/Web/Android на точном SHA, установка wheel/sdist и обновление с реальных PyPI 0.10 и 0.11rc1 с обратной установкой. Публикация требует отдельного разрешения владельца. **Команда `pip install sedrava==0.11.0` станет действительной только после фактического выпуска.** [Критерии](STABLE_RELEASE_GATES_011.md) · [Порядок выпуска](RELEASE_TRACK_011.md) · [Совместимость](COMPATIBILITY_010.md).
