# Web UI 0.11 — экспериментальный срез A

Реализован в исходниках ветки `feature/web-ui-011-slice-a`; это не опубликованная версия 0.11. Версия пакета пока остаётся 0.10.0rc2. Ранее опубликованный RC2 **не содержит** новый режим. Синтаксис приложений и команды `build web` / `build android` сохраняют прежний смысл. [English reference](WEB_UI_011.en.md).

## Сборка и просмотр

Из checkout этой ветки установите `python -m pip install .`, затем:

```sh
sedrava check examples/web_ui_011_landing.sdr
sedrava build site examples/web_ui_011_landing.sdr --output build/site
python -m http.server 8000 --directory build/site
```

Откройте `http://localhost:8000/`. Результат: HTML каждой страницы, `site.css`, favicon, локальные изображения с хешами в именах и `sedrava-site.json` с контрольными суммами. JavaScript, внешние шрифты, фреймворк и Node для сборки не нужны. Эталон содержит две страницы, работает отдельно от рабочего сайта Sedrava. Развёртывание не выполняется.

`check` проверяет весь сайт, ресурсы и внутренние ссылки без записи файлов. `run`, `test`, `build web`, `build android` явно отклоняют документы сайта: состояния и действий приложения здесь нет. Браузерные проверки запускаются отдельно.

## Синтаксис

```text
site "Мой сайт"
theme:
    accent "#B59BFF"
style feature:
    padding 28
    radius 24
    shadow soft
page home at "/":
    title "Мой сайт — начало"
    description "Независимый статический сайт"
    lang "ru"
    container max 1160 padding 24 md-padding 40:
        column gap 32:
            heading "Описал — получил."
            paragraph "Один исходник без ручного HTML." variant lead
            row gap 16 wrap:
                button "Возможности" to "#features"
                link "Исходники" to "https://github.com/VasiliiBabkin/sedrava" target blank
            grid id features columns 3 md-columns 2 gap 20:
                card style feature:
                    heading "Общая основа" level 2
                    paragraph "Типизированные параметры и безопасные значения."
```

Отступ — четыре пробела; табуляция запрещена. У контейнера обязательны `:` и дочерние элементы; у листового компонента дочерних элементов быть не может. Параметры задаются парами `имя значение`; показанная строка может быть позиционным аргументом. `wrap` означает true, `wrap false` отключает перенос. Используется общий декодер строк Sedrava: `\n`, `\r`, `\t`, `\"`, `\\`. Лимиты: 1024 Unicode-скаляра в литерале, 100000 символов исходника, глубина 32. Ошибки содержат строку и колонку. Комментарий `#` занимает отдельную строку; комментарии после выражения не поддерживаются.

Нужна корневая страница `/`. Остальные маршруты имеют вид `/components/`: безопасные ASCII-сегменты и завершающий `/`. Имена и маршруты уникальны. `title` обязателен, `description` и `lang` необязательны (язык по умолчанию en). На странице ровно один h1. Без `level` первый заголовок становится h1, остальные h2; явные уровни 1–6 не могут пропускать промежуточный уровень. ID уникален на странице; `content` зарезервирован для перехода с клавиатуры к основному содержимому. Внутренние маршруты и якоря проверяются.

## Компоненты

| Компонент | Содержимое и параметры | Результат |
| --- | --- | --- |
| `page` | Имя, маршрут, title, description, lang, дети | HTML-документ с main |
| `container` | Дети; max по умолчанию 1160 | Центрированный блок |
| `row` | Дети; gap 16, wrap true | Переносимая flex-строка |
| `column` | Дети; gap 16 | Flex-колонка |
| `grid` | Дети; columns 1–12 (по умолчанию 3), gap 20 | Адаптивная сетка |
| `heading "текст"` | level; variant default/display | h1–h6 |
| `paragraph "текст"` | variant default/lead/eyebrow/muted/brand | Абзац |
| `link "текст"` | Обязательный to; target self/blank; variant default/quiet | Ссылка |
| `button "текст"` | Обязательный to; target self/blank; variant primary/secondary/ghost | **Ссылка**, оформленная кнопкой |
| `card` | Дети; padding 28, radius 24; variant default/highlight/muted | Article |
| `image "assets/picture.svg"` | Обязательный alt (пустой для декора) | Изображение с lazy loading |
| `spacer` | size 0–4096, по умолчанию 24 | Декоративный отступ |
| `divider` | Общие визуальные параметры | Разделитель |

Общие параметры компонентов (не метаданных page): `id`, `label` (ARIA), `style`, `gap`, `padding`, `margin`, `width`, `max`, `height`, `size` (шрифт), `radius`, `color`, `background`, `align`, `justify`, `text-align`, `weight`, `shadow`. Целые CSS-пиксели: gap/padding/margin/height 0–4096, width/max 1–4096, шрифт 10–160, radius 0–256. Width принимает также auto/full. Ширина ограничена родителем, padding — максимум 10%, margin — 5%. Align: start/center/end/stretch; justify: start/center/end/between/around/evenly; text-align: start/center/end/left/right; weight: normal/medium/semibold/bold; shadow: none/soft/glow. Параметры действуют по правилам соответствующего CSS layout: например align полезен у flex/grid-контейнеров.

Токены темы: background, surface, foreground, accent, gold, muted, border. В theme разрешены непрозрачные цвета `"#RGB"` / `"#RRGGBB"`. У компонента можно указать такой цвет или имя токена без кавычек. Произвольный CSS запрещён. Именованный style содержит по одному свойству на строку, не задаёт id/label/другой style. Свойства проверяются относительно компонента, использующего стиль.

Приоритет: встроенные значения → именованный стиль → параметры компонента. Префиксы `sm-` (640px), `md-` (768px), `lg-` (1024px) задают переопределения от минимальной ширины. Они применяются после базовых значений. Семантические параметры text/to/src/alt/level/id/label/style/variant не адаптивны. По умолчанию grid имеет одну колонку до 768px, min(2, columns) от 768px и columns от 1024px. Явное число колонок в брейкпоинте заменяет автоматическое значение. Более широкий брейкпоинт перекрывает предыдущий для одного свойства.

## Безопасность и повторная сборка

Текст и атрибуты экранируются. Ссылки: HTTP/HTTPS, mailto без заголовков, tel, объявленные маршруты и якоря. Учётные данные в URL, protocol-relative адреса, обход каталогов и опасные схемы запрещены. Новые вкладки получают noopener/noreferrer. Удалённые изображения — только HTTPS; генератор не загружает и не проверяет их. С ними автономность не гарантируется; эталон использует только локальный ресурс.

Локальные пути считаются от `.sdr`, а не текущего каталога. Символические ссылки и выход за каталог исходника запрещены. PNG/JPEG/WebP проверяются по сигнатуре (не полным декодером). SVG должен иметь UTF-8 и допускает ограниченные геометрию/текст: без скриптов, стилей, внешних ссылок, entities и анимации. Лимиты — 2 MiB на ресурс и 16 MiB уникальных ресурсов. Генерируется ограничительная CSP; пользовательские JS/CSS отсутствуют. Контраст собственных цветов обязан проверить автор.

При одинаковом исходнике, ресурсах и компиляторе байты сборки одинаковы. Манифест не содержит времени или абсолютных путей. Разрешён новый/пустой каталог; повторная сборка требует неизменённого точного набора ранее сгенерированных файлов. Посторонние или изменённые файлы защищены отказом сборки. Проверка и подготовка временного дерева предшествуют замене; ошибка замены восстанавливает прежний каталог. Это гарантия при обычных файловых ошибках, а не протокол защиты от потери питания или параллельной публикации. Не храните пользовательские файлы в результате сборки. Пересечение с исходником/ресурсами запрещено.

## Архитектура, проверки и границы

`sedrava_frontend.parse_document` выбирает режим по первому объявлению. Общими остаются ограничения исходника, обработка строк и позиции ошибок. У сайта типизированный AST представления: виджеты действий приложения не описывают статический layout. Реестр `sedrava_site.COMPONENTS` содержит теги, параметры, правила вложенности и варианты; обычный новый примитив не требует ветки в парсере или рендерере. `site_codegen` отвечает за CSS, ресурсы и безопасную запись. Сложным виджетам всё равно потребуются семантика и тесты.

Естественный синтаксис PR #21 сохранён. Уточнены style, метаданные страниц, брейкпоинты, проверка ссылок/заголовков, лимиты ресурсов. Button — навигационная ссылка с обязательным to: неработающие кнопки и произвольные обработчики означали бы обещание отсутствующей функциональности. Добавлены требуемые spacer/divider. Второй язык выражений и действий не создавался.

Проверки: `python -m unittest discover -s tests -v`; `python scripts/test_site_browser.py` (Playwright 1.62.0 и Chromium). Браузер сохраняет скриншоты 360/768/1440, трассы, фокус, семантику и измеренный контраст стандартного текста в `build/site-evidence`. Проверяются настоящие переходы, Back/Forward, клавиатура, reduced motion, переопределение layout, Unicode и опасная разметка; JavaScript-ошибки и HTTP-ошибки считаются провалом. Это не полная сертификация WCAG и не проверка экранным диктором/физическим устройством. Отдельный workflow с read-only правами сохраняет артефакт `sedrava-web-ui-011`, фактический SHA и хеши; ничего не развёртывает.

Следующие компоненты **запланированы**, но не реализованы: семантические navbar/footer, badge/callout, code block, навигация документации; затем формы, accordion, tabs, dialog. Привязка состояния, пользовательские переиспользуемые компоненты, произвольный JS/CSS, Android для сайтов и замена рабочего сайта не входят в Slice A.

## Дополнения Slice B (только ветка разработки)

Добавлены `navbar` (верхняя навигация), `footer` (подвал),
`callout` (примечание с вариантами default/info/warning)
и `code` (экранированный блок исходного текста).

Пример: `code "state x = 0\\npersist x"`. Код выводится как
`<pre><code>`, **не исполняется**, и может прокручиваться по горизонтали.

`navbar` и `footer` необязательны; допускается не более одного каждого
на страницу. Навигация должна находиться первым компонентом страницы,
подвал — последним, вне вложенных контейнеров: итоговая разметка
содержит `nav` до `main`, а `footer` после `main`.
Это экспериментальный Slice B, не стабильный выпуск языка.
