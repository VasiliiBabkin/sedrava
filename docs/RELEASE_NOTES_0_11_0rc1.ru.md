# Sedrava 0.11.0rc1 — заметки к готовящемуся релиз-кандидату

**Кандидат ещё не опубликован.** Последняя выпущенная версия — [0.10.0](https://github.com/VasiliiBabkin/sedrava/releases/tag/v0.10.0). Описаны возможности исходников в `release/011-rc1-preparation`, а не уже опубликованный выпуск.

## Возможности кандидата

- `sedrava build site` создаёт адаптивные многостраничные сайты с проверяемыми компонентами, стилями и локальными ресурсами.
- `sedrava build webapp` создаёт интерактивные приложения в браузере с типизированным состоянием, действиями, списками, формами, таблицами, диалогами и навигацией.
- Реализованы чистые функции, локальные переменные и ограниченные преобразования коллекций.
- HTTP-клиент поддерживает GET/POST/PUT/PATCH/DELETE с проверкой схем и ограничениями. Работающий сервер предоставляется отдельно.
- Четыре примера: `platform_site.sdr`, `platform_tasks.sdr`, `platform_catalog.sdr`, `platform_crm.sdr`.

## Совместимость и ограничения

- Опубликованная 0.10.0 не изменена; прежние программы и команды остаются предметом регрессионных тестов.
- Пространства имён с алиасами и проверяемые пакеты входят в экспериментальную линию **0.12**, а не в этот кандидат.
- Генератора серверных программ, SQLite/PostgreSQL, аутентификации и разграничения доступа пока нет.
- Хранение состояния браузера локальное; миграции данных и проверка на любом физическом Android-устройстве не гарантированы.

## Статус выпуска

Проверять код можно из отдельной ветки кандидата. Установка `pip install sedrava==0.11.0rc1` и тег `v0.11.0rc1` станут допустимыми инструкциями только после фактической публикации.
