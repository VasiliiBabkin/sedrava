# A30 — согласованный alpha-выпуск платформы

Целевой комплект: Sedrava 0.12.0-alpha.3, SedravaSQL 0.1.0-alpha.2, нативный NativeLog CLI 0.0.2. Linux x86-64 GNU, проверка на Ubuntu 24.04. Три CLI в одном архиве: sedrava (язык/сервер), sedravasql-native-preview (ограниченный SQL на NativeLog), sedravasql (отдельный SQLite key/value API). Два формата данных несовместимы. Не использовать для ценных данных, не публиковать сервер проекта в интернет.

## Сборка и проверка

Закреплённый SQL-коммит: b36a628c95598a3e8e04b40ebf9c86cdc20e0604. Собирать оба репозитория из чистых точных коммитов с Cargo --locked --release. Для нативного CLI использовать native-engine/Cargo.toml; для managed CLI — корневой Cargo.toml. Упаковщик проверяет версии всех трёх бинарников, целевую архитектуру, точные исходники и состояние Git, формирует манифест и SHA-256. Детерминированность архива проверяется повторной упаковкой одинаковых бинарников, не независимой компиляцией.

После проверки архива:
```sh
# ARCHIVE и HASH — имя архива и SHA-256 из доверенного опубликованного манифеста.
sh install_platform_a30.sh "$ARCHIVE" "$HASH" "$HOME/sedrava-alpha3"
export PATH="$HOME/sedrava-alpha3/bin:$PATH"
sedrava --version
sedravasql --version
sedravasql-native-preview --version
sedrava new myapp
cd myapp
sedrava test
sedrava build
```

Установщик требует стандартные GNU utilities, не Python/Rust, не сеть и не sudo. Новый абсолютный префикс с существующим доверенным родителем. Не заменяет старую установку. Контрольная сумма не цифровая подпись. Для авторизации и данных см. PROJECT_CLI_A25.ru.md и SERVER_SESSIONS_A23D.ru.md в комплекте. База проекта — новый приватный каталог; миграции добавочные. Прежние базы A25 не присваиваются автоматически.

Тесты упаковки: scripts/verify_platform_a30.py ARCHIVE. Проверить все три версии, managed SQLite операции, native SQL lifecycle, отказы при повреждении и повторной установке, A24/A25 HTTP и при наличии jsdom — DOM. Дополнительная полная регрессия A16–A25 обязательна перед выпуском. A27 независимая CI проверяла исходный A26 до изменения версий; не приписывать её новым бинарникам. Публикация только после успешной квалификации точного кандидата.
