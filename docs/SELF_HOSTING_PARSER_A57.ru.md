# A5.7 — таблица символов и статический анализ скалярных выражений

Экспериментальная программа examples/self_host/parser_a57.sdr расширяет A5.6c. Внешний декларативный контекст передаётся строкой declarations (до 256 Unicode scalar, <=32 symbols). Одна строка `name v i` для переменной или `name f ib i` для функции (тип параметров в порядке, затем результат; '-' = 0 аргументов; <=8 параметров). Коды i/b/t = int/bool/text. Общая таблица имён, без областей видимости, перегрузок, пользовательских record/Result. load_symbols проверяет имена, повторные символы, формы объявлений и сигнатуры. analyze обходит AST в postorder: каждому узлу сопоставляет тип и ID разрешённого символа, проверяет аргументы, группы, арифметику, unary/logical/comparison, тип условия bool и совместимость присваивания. '/' пока отклоняется (не поддержан нативным парсером); целочисленные литералы синтаксически проверены, диапазон чисел и вычисление переполнений отдельный этап. Разбор объявлений из полноценного исходника, проверка областей видимости и генерация исполнимого кода остаются pending. Это не весь компилятор и не type checker всей грамматики Sedrava.

VDS: 7 корректных типизированных программ, 16 семантических ошибок, 5 ошибок объявлений, 2 sequencing guards PASS. Проверяется код и диапазон ошибочного выражения, ID символов и типы корней. Семантика выполняется самим Sedrava, Python лишь запускает и сверяет результаты. Команда: SEDRAVA_NATIVE_BIN="$CARGO_TARGET_DIR/release/sedrava-native" python3 -B scripts/verify_selfhost_parser_a57.py (существующая release сборка).
