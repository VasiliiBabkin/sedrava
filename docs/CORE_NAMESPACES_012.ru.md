# Интеграция пространств имён и ограниченного ядра 0.12

Экспериментальная, неопубликованная 0.12.0a1; Android versionCode 12001.
Основа — #47 с сохранённой историей #50/#51. Стабильная ветка и серверные PR
не изменяются. [English](CORE_NAMESPACES_012.md) · [Проверки](CORE_NAMESPACES_012_STATUS.md).

## Модули как часть языка

Рабочие примеры: examples/modules_core_012/main.sdr для Web/Android и соседний
site.sdr для WebApp. Оба импортируют один model.sdr, тот — text.sdr. Правка
сгенерированного кода не требуется.

Модуль поддерживает record/fn/component/style, а теперь также state/derive/action и собственные инварианты rule.
Символ доступен через импорт только при export. persist сохраняет собственное
состояние модуля. Действия и вычисляемые значения не могут неявно обращаться к
состоянию входного приложения; разрешены собственные символы и явные экспорты
импортируемых модулей. Импорт не выполняет действия автоматически.

```sdr
module sample.counter
export state numbers: list<int>(max=4) = [3, 1, 2]
export state total = 0
persist numbers
persist total
export action scan:
    total = 0
    for index, value in numbers:
        total = total + value
        numbers = list_replace_at(numbers, index, value * 2)
rule total >= 0
```

Входной файл использует `import "counter.sdr" as counter`, `value counter.total`
и `button "Scan" -> counter.scan`. В WebApp кнопка задаётся как
`button "Scan" action counter.scan`. CLI: `sedrava run main.sdr counter.scan`.

Параметры функций, let и переменные циклов изолированы от имён входного файла.
Перекрытие собственного символа модуля или псевдонима импорта запрещено. Циклы
находятся в обычных действиях; функции остаются чистыми выражениями. Рекурсии,
неограниченных циклов и второго интерпретатора функций нет. Импорты упорядочены
по зависимостям, проверяются на циклы и не дублируют определения. Проверяются
также приватные и неиспользуемые объявления.

Все новые типы, Unicode и Result используют общее строго типизированное ядро.
Result по-прежнему временный, с фиксированными ошибками; вложенные списки,
Map/Set и сохраняемые пользовательские варианты ошибок не добавлены.

## Общие ограничения и данные

Развёрнутый граф проверяется целиком: ограничения функций, типов, исходников,
AST, вложенных циклов, вызовов и инвариантов не сбрасываются на границе модуля.
Бюджет действия — 1 000 000 единиц работы и не более 10 000 инструкций.
Граф ограничен 32 модулями и глубиной 16; суммарные исходники и результат
развёртывания — по 100 000 символов. Оценка консервативна. Сохраняются int32,
1024 Unicode-скаляра и закреплённая нормализация Unicode 15.0.0.

Переименование псевдонима импорта сохраняет идентичность состояния и записей.
Смена имени модуля/состояния/типа или вместимости может сделать снимок
несовместимым. Автоматической миграции нет. Отклонённые данные не перезаписываются.
Приватность символов — правило разрешения имён, не защита секретов в браузере.

## Диагностика и безопасность

Пути, строки и колонки исходных файлов сопровождают замену имён и подстановки
компонентов. JSON и текстовая диагностика различают компиляцию и выполнение;
ошибка импортированной функции указывает на её тело, включая вложенные импорты.
Поиск неизвестного имени не принимает совпадение внутри строки за позицию ошибки.
Некоторые ошибки всего проекта имеют только позицию объявления/файла: это пока
лексическое развёртывание, а не полноценная многофайловая typed-IR symbol table.
Локальные пути разработчика не встраиваются в сообщения пользовательского UI.

Сгенерированные M_/L_ имена запрещены в исходниках и аргументах действий CLI.
Не-ASCII идентификаторы не нормализуются неявно в приватные имена. Unicode-текст
в строках не ограничивается ASCII.

В Python 3.10 для lock/verify нужен объявленный extra: `python -m pip install '.[packages]'`
из этого checkout либо установка локального wheel с `[packages]`. В Python
3.12/3.13 используется tomllib стандартной библиотеки. Обычные команды модулей
работают и при базовой установке.

Локальные пакеты требуют точных версий и проверенного SHA-256 lock. Импорт из
vendor/ обязан входить в lock; проверяются именно прочитанные компилятором байты.
Обход каталогов, символьные ссылки, циклы и незакреплённые файлы запрещены.
true, float и NaN вместо целочисленной схемы отклоняются. Слишком большой lock
не заменяет предыдущий файл. SHA-256 не является подписью автора; команда lock
фиксирует результат явного просмотра изменений. Реестра и загрузки кода из сети нет.

## Проверка примеров

Команды полного воспроизведения приведены в английской версии. Пример содержит
встроенные тесты, допускает check/test/run и сборки web/android; соседний site.sdr
собирается командой build webapp. Пакеты wheel/sdist включают модульный пример и
проект локальных пакетов с lock. Выходной файл не может перезаписать импортируемый
исходник, выходной каталог — содержать исходные файлы.

Фактические результаты Python/JS/Kotlin, браузеров, API35, чистой установки и CI
записываются в журнал и PR на точном SHA. Проверка физического устройства не
подразумевается успешной сборкой APK. Выпуск и объединение требуют отдельных решений.

В scoped-графе компоненты и слоты содержат только UI, без доменных инструкций.
Старое развёртывание без пространств имён сохраняет поведение 0.11: один пример
с подстановкой инструкции действия проверяется опубликованным пакетом, кандидатом
и после отката. Этот путь совместимости не ослабляет изоляцию scoped-модулей.

Обход пакета итеративный, с проверкой **до** сортировки: не более 1 024 записей
каталога, включая пустые каталоги, глубина 16 и 1 024 символа относительного пути
на зависимость; сохраняются пределы 256 файлов и 8 МиБ. Скрытые записи и симлинки
запрещены. Обычные пустые каталоги в пределах лимитов не меняют lock-файл.
Превышение лимитов не заменяет существующий lock-файл.

## Разрешение идентификаторов

Зарезервированные слова, включая `true`/`false`, проверяются до переименования.
Параметры чистых функций и переменные действий не могут перекрывать явный
псевдоним импорта — ни в модуле, ни во входном файле. Аннотации типов, выражения,
имена объявлений и служебные слова обрабатываются раздельно: допустимый пример
`fn identity(int: int) -> int = int` сохраняет смысл. Метка поля записи не
превращается в квалифицированную ссылку. Однострочные действия используют те же
области локальных переменных и исходные колонки, что и многострочные.

Ядро и lowering используют общую грамматику функций/параметров и предел восемь
параметров. Замены символов и их координат выполняются пакетом, без повторного
копирования всей строки. Области имён и текущий владелец объявления поддерживаются
последовательно, без поиска по всем предшествующим строкам.
