# Known limitations

Current Rust alpha is not production-ready. Linux x86-64 is tested; no Windows/macOS acceptance. Browser DOM checks do not prove real browser parity. Android generator supports a subset; debug APK build and limited device tests do not establish full acceptance. Some target constructs are rejected. No arbitrary public SQL server, proven network security, full migration or hardware power-loss guarantees. Use disposable state and private directories. NativeLog SQL B23 is separate from pager/tree B25. Self-host compiler is an experiment.

Historical comparisons do not prove complete compatibility. [History](HISTORY.md) · [Roadmap](ROADMAP.md) · [Security](SECURITY.md).
