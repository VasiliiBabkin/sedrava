# A5.6c — AST вызовов функций

`examples/self_host/parser_a56c.sdr`: вызов именованной функции с нулём, одним или несколькими позиционными аргументами, включая вложенные вызовы, арифметические и логические выражения в аргументах и условиях. Call-узел хранит имя, диапазон исходника, left_id=0 для пустого списка или корень дерева аргументов. Для двух и более аргументов создаются left-associated узлы arguments с разделителем comma; порядок сохраняется. Запятые разрешены только внутри вызова на соответствующем уровне скобок. Ошибочные запятые, пустые аргументы, невалидный callee, вызов результата вызова, именованные аргументы отвергаются. Лимиты предыдущих этапов сохраняются. Разрешение имён, сигнатур, типизация, выполнение вызовов и полная грамматика не реализованы.

VDS: 17 корректных программ и 14 отклонённых, независимый Python AST oracle проверяет форму дерева, порядок аргументов, связность, диапазоны, if/else. PASS с существующей release-сборкой. Команда: SEDRAVA_NATIVE_BIN="$CARGO_TARGET_DIR/release/sedrava-native" python3 -B scripts/verify_selfhost_parser_a56c.py.

Регрессия A5.6b (9/11 + guard) также PASS.
