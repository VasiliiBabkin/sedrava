# Sedrava Native: сохранения и типизированный IR (эксперимент)

Последнее обновление: 22 ноября 2026 г.

Этот документ описывает только реализованный на Rust прототип. **Полного
переноса Sedrava 0.11 пока нет**. Python остаётся основным компилятором,
особенно для Web, Android, Site, WebApp, импортов и Host API.

## Требования

- Рабочее окружение Rust/Cargo (версия toolchain в rust/rust-toolchain.toml).
- Компиляция из корня репозитория: cargo build --manifest-path rust/Cargo.toml --locked.
- Для перекрёстной проверки Python/Rust — Python 3.12 или совместимая версия.

## Сохранение состояния

Пример использует **только отдельный файл с тестовыми данными**:

    ./rust/target/debug/sedrava-native run tests/rust_cases/persistent_records.sdr add --state-file example-state.json
    ./rust/target/debug/sedrava-native run tests/rust_cases/persistent_records.sdr complete --state-file example-state.json

Ключ --state-file можно указать и до имён действий. CLI читает файл,
если он существует, проверяет сигнатуру схемы и типы, выполняет действия
на временной копии, затем записывает принятое состояние атомарной заменой.
Если действие отклонено, запись не выполняется.

Совместимый формат: JSON с полями schema=1, signature и state.
Подпись зависит от **порядка объявлений переменных**, их типов, полей
записей, вместимости коллекций и меток persist, как в Python 0.11.
В сохранение попадают **только отмеченные как persist переменные**,
не производные значения. ID записей и счётчик next_id сохраняются.

При чтении отклоняются неправильные схемы, дублирующиеся ключи JSON,
дробные или выходящие за int32 числа, неверные поля и ID, повреждённые
записи, нарушающие правила (rule), а также слишком большие снимки.

**Ограничения:** тесты не подтверждают сохранность при потере питания,
конкурирующих процессах, повреждении диска, а также семантику Windows/macOS.
Перед реальным использованием нужны резервное копирование и отдельные
испытания. Файл не шифруется.

## Экспорт типизированного IR

    ./rust/target/debug/sedrava-native ir tests/rust_cases/persistent_records.sdr

Команда выдаёт JSON со схемой sedrava-native-typed-ir, версией 1,
описанием типов, действий, правил, экранов и функций. Добавлена карта
верхнеуровневых объявлений declarations с номерами строк и столбцов.

**IR экспериментальный и пока не является стабильным ABI.** Для выражений,
вложенных конструкций и модулей нет полного отображения исходных позиций.
Web/Android-генераторы ещё не используют этот IR.

## Проверяемые команды

    cargo fmt --manifest-path rust/Cargo.toml --all -- --check
    cargo test --manifest-path rust/Cargo.toml --locked --all-targets
    python3 scripts/verify_rust_snapshot.py
    python3 scripts/verify_rust_core.py --random-cases 24

Проверка сохранений создаёт временные файлы, проверяет двустороннее чтение
Python/Rust и ряд сценариев отклонения некорректных JSON. Она не подменяет
испытания с реальным отказом питания.
