# Экспериментальное ядро Sedrava A1 — индексы, Unicode, циклы, списки и ошибки

**Черновая разработка, не опубликована.** Стабильная версия 0.11.0 и экспериментальная ветка пространств имён 0.12 не изменены.

## Текст и Unicode

~~~sedrava
app "Пример"
state text = "A😀Б"
derive symbol = text[1]
derive part = text[1:3]
derive where = text_index(text, "Б")
derive number = unicode_ord(symbol)
derive again = unicode_chr(number)
~~~

Индексы считаются по **кодовым точкам Unicode**, а не байтам или UTF-16. Комбинируемые знаки — отдельные кодовые точки, а не один графемный кластер. Максимальная длина текста — 1024. Также поддерживаются text_at(text,index), text_slice(text,start,end), text_index(text,needle), unicode_ord(text) и unicode_chr(int). Границы среза обязательны, правая не включается. Отрицательные индексы, выход за границы и недопустимые Unicode scalar values вызывают ошибку, без обрезки значений. Нормализации пока нет.

## Циклы

~~~sedrava
action sum:
    repeat i in range(0, 5):
        total = total + i
~~~

Счётчик i принимает значения от 0 до 4. Верхняя граница — буквальное число 1–100. Имя счётчика действует только внутри цикла. Вложенные циклы проверяются по максимальному количеству шагов, предел действия — 10 000. Нет неограниченного while, рекурсии и break/continue. При ошибке исходное состояние не меняется.

## Коллекции

Ограниченные списки записей (до 100 элементов) дополнены позиционными операциями: list_at(items,index) / items[index], list_slice(items,start,end) / items[start:end], list_clear(items). ID записей сохраняются, next_id не откатывается. Поиск по идентификатору остаётся отдельной операцией get(items,id). Неограниченные списки, множества и словари пока отсутствуют.

## Структурированные диагностики

Команда: sedrava --diagnostics=json check examples/bounded_core_012.sdr

При ошибке CLI выдаёт JSON в stderr с code, phase, message и location (source, line, column). Неизвестные позиции обозначаются null, не придумываются. Обычный текстовый вывод по умолчанию сохранён. Это пока не встроенные языковые конструкции try/catch и Result, а машинно-читаемые ошибки компилятора и CLI.

Для объединения необходимы реальный CI Python/Web/Android, тесты сборки wheel/sdist и обратная совместимость. Полная спецификация на английском — BOUNDED_CORE_012_A1.en.md.
