# Нативная генерация Web на Rust (первое проверяемое подмножество)

**Это экспериментальная реализация, не замена Web-генератора Sedrava 0.11.**

Rust теперь может без запуска Python создать автономную HTML-страницу из
обычного приложения с одной экранной формой, скалярными состояниями и
простыми выражениями.

## Что проверено

- Вывод текста, состояния и вычисляемых значений (derive).
- Кнопки с действиями, условиями и правилами (rule).
- Ввод int32 и text, проверка переполнения и лимита Unicode.
- Условный показ текста через show, защита строк при вставке в HTML/JS.
- Генерация HTML и проверка JS синтаксиса.
- Исполнение скрипта в Node.js с тестовым имитатором DOM.

## Команды из корня репозитория

    cargo build --manifest-path rust/Cargo.toml --locked --bin sedrava-native
    ./rust/target/debug/sedrava-native build web examples/counter.sdr --output build/native-web/index.html
    python3 scripts/verify_native_web.py

Полученный HTML — автономная локальная страница, без загрузки библиотек.
Проверка скрипта с Node.js не равна полноценным браузерным тестам.
Пример для ввода и вычисляемых значений:
tests/rust_cases/native_web_ui.sdr

## Что ПОКА запрещено

Нативная команда build web явно отказывает, а не упрощает программу молча,
если исходник содержит: persist, records/list, чистые функции/запросы,
навигацию/несколько экранов или неподдерживаемые Site/WebApp компоненты.

Все перечисленные возможности остаются доступными в действующем
Python-компиляторе. Нельзя считать скорость/совместимость этого прототипа
скоростью/совместимостью Web-платформы Sedrava целиком.

В разработке также локальный импорт функций и record-деклараций в Rust
(команда expand FILE). Он не заменяет компонентные макросы Site/WebApp.

Дальнейшие задачи — запись/чтение persist через браузер, списки,
pure functions, навигация, реальная browser acceptance, затем остальные
генераторы. Статус: [задача №65](https://github.com/VasiliiBabkin/sedrava/issues/65).
