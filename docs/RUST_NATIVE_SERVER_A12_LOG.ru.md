# A12/A13 — атомарная запись через нативный журнал SedravaSQL

Экспериментальный loopback-сервер с `--transactional --native-log ABSOLUTE_FILE`. Файл должен быть предварительно создан `sedravasql-native-preview init`, находиться в приватном каталоге и открываться только одним владельцем. Нельзя сочетать режим с SQLite, state-dir, journaled или native-index. Поддерживаются read-only GET и существующие A9 PUT с ровно двумя db_batch_put, четырьмя полями и одним set. Другие изменяющие маршруты отклоняются до открытия сокета. Сборка всё ещё включает SQLite для прежних режимов; в A12 SQLite-файл не открывается.

Один commit_batch пишет две бизнес-записи, снимок состояния с привязкой к SHA исходника и HTTP-квитанцию в зарезервированном пространстве sedrava_native_a12. Каждая операция имеет CAS; запись подтверждается только после sync_all. При повторе старого Idempotency-Key возвращается сохранённый исходный ответ и ревизии до вычисления нового состояния; другой fingerprint -> 409, конфликт CAS -> 412. Квитанция сверяется с исходной NativeCommit. GET использует B13 read_snapshot. При неопределённом результате сервер прекращает обслуживание. Первый запуск допускает только пустой журнал; изменение исходника существующего приложения требует отдельной миграции (пока не реализована). Внешние записи в файл вне сервера не поддерживаются.

A13 проверяет штатный restart, debug fault after_sync (потеря ответа после синхронизации) и after_payload (оборванный кадр). Блокировка после сбоя сохраняется; оператор должен проверить владельца и разрешить дальнейшие действия. В тесте удаляется только собственная блокировка после подтверждённого выхода дочернего процесса. Повреждённый журнал не усекается автоматически. Это проверка завершения процесса, не тест физического обесточивания. Для recovery используется отдельная ранее реализованная offline-копия B1; автоматической миграции и production-гарантий нет.

VDS: 83 Rust tests, A12/A13 real loopback HTTP PASS, A11 regression PASS, A10 SQLite regression PASS (242 согласованных чтения / 81 поколение записи). Зависимость B13: 884f9339d78f7b60d35b3a4ac65277f2af286720. Пример examples/native_server/native_a12_log.sdr.
