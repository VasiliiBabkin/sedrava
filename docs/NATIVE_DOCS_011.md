# Native documentation / Нативная документация (experimental 0.11)

This optional compiler feature extends site mode, not the published 0.10 package. Install the reviewed dependencies with `pip install '.[docs]'` (markdown-it-py 4.0.0, Pygments 2.19.2). Existing app/site builds without these components need no docs dependency.

- `markdown "content/guide.md"`: root-confined UTF-8 Markdown, up to 256KiB/file, 4MiB declared document inputs, 512 dependencies, 10000 block tokens/file. CommonMark with tables, headings/unique Unicode anchors, lists, emphasis, fenced code and links. Raw HTML and Markdown images reject; use typed image nodes. H1 belongs to the containing page; Markdown starts at h2. Frontmatter is metadata and is not executed. Links pass the existing URL validator and resolve against declared site routes. The renderer produces a table of contents, escaped syntax-highlighted code and visible copy controls. Line numbers are a separate aria-hidden, unselectable gutter; they are never included in code text, copied source or its hash. Runtime code comes from a fixed compiler adapter, not source JavaScript.
- `search label "Search documentation"`: deterministic local index of Markdown titles/headings/body/code across languages, embedded in external docs.js, with no runtime search request or API key. Cyrillic/Latin case matching, keyboard down/up/Escape and safe text excerpts. Index <=2MiB, 160-character input and 30-result bound. Search data is public.
- `sidebar label "Documentation":`: semantic nested navigation; ordinary checked links automatically mark the current site route with aria-current.
- `demo "demos/counter.sdr" at "/live/counter/" label "Counter"`: compiles a local trusted WebApp and declared dependencies into a separately owned route, with the original exact UTF-8 source/download/hash beside a live iframe. At most sixteen demos, checked route ownership/collisions. The child HTML/CSS/JS is byte-identical to separate WebApp compilation. Site metadata/styles are not injected into child outputs. Main build manifest includes dependencies, and docs-demos.json binds source/artifact hashes.

Demo iframes are **trusted author code on the same origin**, not a security sandbox. No arbitrary source editor, HTML, event handler string or eval is accepted. Source review and separate-origin isolation are prerequisites for any future untrusted playground. Camera/microphone/geolocation/payment are denied; CSP enables only self scripts/frames. Browser same-origin privileges remain; no isolation claim is made. Reload affects the frame. Explicit reset deletes only the known demo path/name state/cache, never localStorage.clear(). A static host cannot supply a pretend live API; external demo endpoints must be independently provided or clearly CI-only.

Local sources, modules, resources and output routes are bounded and hashed. Failed validation occurs before replacing managed output. No build-time network access or publication. Generated docs are static files suitable for Nginx, including the optional fixed client search/copy/reset adapter.

Русский: Markdown, поиск, боковая навигация и встроенное WebApp — проверяемые компоненты site. Установка extras `[docs]` обязательна для них. HTML отклоняется; текст и код экранируются; URL проверяются; зависимости ограничены корнем и хешируются. Пример собирается из того же файла, который показан рядом, без ручных изменений генерации. Общий origin означает доверие к автору примера, а не изоляцию. Произвольный редактор/недоверенный код не поддерживается. Reset удаляет только состояние конкретного примера. Статический сайт не имитирует сервер API. Выпуск/развёртывание эта возможность не выполняет.


`clean-urls true` opts a static site into relative directory links instead of explicit index.html links, preserving existing defaults. Demo reload preserves its accepted route/hash; reset returns to the declared demo entry after scoped storage deletion. Нативная перезагрузка сохраняет hash-маршрут, reset удаляет только данные выбранного примера.

Embedded WebApp navigation owns a bounded frame-local route trail and replaces its frame hash without adding entries to the host page history. Its Back control returns within that demo; the browser Back button remains document navigation. Standalone WebApp Browser Back/Forward behavior is unchanged. Reload preserves the current frame hash; reset replaces the frame entry after scoped storage deletion. This avoids joint iframe-session history interactions across independent demos, notably in WebKit.
