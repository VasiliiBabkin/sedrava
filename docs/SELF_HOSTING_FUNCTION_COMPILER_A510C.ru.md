# A5.10c — function bodies and local slots

The experimental self-hosted compiler accepts the A5.10b one-line integer function syntax and a new strictly four-space-indented block syntax `fn name(a: int) -> int:` followed by zero or more `let name = expression` and one final `return expression`. No shadowing, mutation or branch statements. Parameters and initialized locals occupy independent frame slots; locals are added to the symbol table only after their initializer is lowered. Reject duplicate declarations, use before declaration, cross-function scope leakage, missing or non-final return, invalid indent and overflow. Retain A5.10b arithmetic, static call resolution, arity and precedence. Up to 8 slots including parameters, 8 statements, 100 tokens/instructions, 16 functions, 8 frames, 256 executed instructions; input and runtime budgets apply. This is an experimental source syntax, not yet supported by the main Rust compiler. No full lexical block scopes, conditional bodies, typed diagnostic API, or whole-language self-hosting claim.

VDS: 5 valid source programs, 10 invalid/overflow cases and 1 sequencing guard PASS. Reproduce with `scripts/verify_selfhost_function_compiler_a510c.py` and SEDRAVA_NATIVE_BIN pointing at the native executable. Previous A5.10b prototype retained.
