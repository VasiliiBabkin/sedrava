# Sedrava Native 0.12.0-alpha.1 — Linux preview

Standalone Rust toolchain for experimental use, not a replacement for stable Python 0.11.0. Linux x86_64 GNU target. Check/test/run, records, bounded collections, functions, Unicode, navigation, Web/Site and Android generators, trusted local Host and loopback SQL API A21. A5.11b self-host compiler remains a separate experiment. Unix SQL API waits on socket readiness with a bounded idle timeout instead of polling by 10 ms sleeps. SQL uses NativeLog B23; B24/B25 are not its backend. No production, cross-platform, full parity, real-browser or exhaustive device claims. Use disposable state.
