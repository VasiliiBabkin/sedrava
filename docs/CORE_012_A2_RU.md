# Экспериментальное строго типизированное ядро A2

Зависимая ветка PR #50, не стабильная возможность 0.11 и не выпуск.
Полный пример: `examples/bounded_values_012.sdr`. Английский справочник с точными
контрактами: [CORE_012_A2.md](CORE_012_A2.md).

## Списки и циклы

`state numbers: list<int>(max=4) = [3, 1, 2]` объявляет список с обязательной
вместимостью 1..100. Поддерживаются int, bool, text и существующие записи.
Типы не преобразуются; вместимость входит в тип параметров и результатов функций.
Списки записей начинаются пустыми и сохраняют прежние устойчивые идентификаторы.
Вложенные списки, Map и Set пока не реализованы.

Операции: append, count, list_at, list_slice, list_clear, list_remove_at,
list_replace_at, list_index, list_capacity. Индексы начинаются с нуля, отрицательные
индексы запрещены; срез требует обе границы без шага. Поиск возвращает -1 при
отсутствии значения. Замена записи сохраняет ID, удалённые ID не переиспользуются.
list_identity переводит позицию в устойчивый ID; get/update/remove/has работают
с ID. list_sort и list_sum доступны скалярным спискам; сумма проверяет int32
после каждого сложения. Текст сортируется по Unicode scalar values.

```sdr
action double:
    for index, value in numbers:
        numbers = list_replace_at(numbers, index, value * 2)
```

Цикл обходит неизменяемый снимок при входе; изменение списка не меняет обход.
Также доступны `for value in numbers:` и обход текста по Unicode-скалярам.
Переменные цикла неизменяемы, локальны и не перекрывают существующие имена.
`repeat i in range(start,end[,step]):` принимает литералы int32, исключает end,
запрещает нулевой шаг и более 100 итераций. Пустые и обратные диапазоны допустимы.

Статический предел — 1 000 000 единиц работы с учётом вложенности, вместимости,
функций, запросов, сортировок, раскрытия вычисляемых значений и инвариантов.
Одинаковый runtime budget проверяется в Python/JS/Kotlin до выполнения инструкции.
Ограничение 10 000 инструкций также сохраняется. Это предел вычислений, не времени.
При ошибке или исчерпании бюджета всё действие откатывается.

## Unicode

unicode_nfc/nfd/nfkc/nfkd используют явно выбранную форму; text_casefold — полное
регистровое свёртывание без локали и турецких исключений. Все платформы используют
одни закреплённые данные Unicode 15.0.0, а не библиотеки среды исполнения.
Обрабатываются Hangul, порядок combining marks и исключения композиции.
Суррогаты запрещены; результат свыше 1024 скаляров отклоняет действие.
Промежуточное разложение ограничено 18*1024 скалярами. Нормализация резервирует
65 536 единиц работы, свёртывание — 4096. Происхождение и SHA-256 данных указаны
в unicode_data/15.0.0/manifest.json, лицензия сохранена и включается в генерацию.

Нормализация при сохранении и сравнении не выполняется автоматически. Поиск
text_index после преобразования возвращает позицию в преобразованном тексте.
Графемные кластеры, локализованная сортировка и новые версии Unicode не обещаются.

## Ожидаемые ошибки

Result<T, Error> — типизированное временное значение для let, derive и функций.
try_add, try_chr и try_at возвращают результат с закрытыми кодами INT_OVERFLOW,
INVALID_SCALAR, INDEX_BOUNDS. result_ok проверяет успех, result_code возвращает
код (пустой при успехе), result_or требует запасное значение того же типа.
Все аргументы вычисляются заранее; неявного извлечения значения нет.

Ошибки аргументов, инвариантов и бюджета не превращаются в ожидаемые ошибки.
Исключения платформы не передаются приложению. Хранение Result в state/JSON,
вложенные Result, пользовательские варианты ошибок и pattern matching пока
не поддерживаются. Схема сохранения скалярных списков — строгие JSON-массивы;
bool/float вместо int запрещены. Изменение типа/вместимости отклоняет старый
снимок; автоматической миграции нет. Формат списков записей остаётся прежним.

Для отдельного среза A2 согласование с пространствами имён не подразумевалось.
Текущая интеграция описана в CORE_NAMESPACES_012.ru.md; серверная платформа
0.13 остаётся отдельной работой. Доказательства проверок и оставшиеся
ограничения публикуются в CORE_012_A2_STATUS.md.
