# Нативное ядро Sedrava на Rust — эксперимент

**Статус:** отдельная экспериментальная ветка. Существующий Python-компилятор и
опубликованная версия 0.11.0 не изменяются. **Не рекомендуется для production.**

## Зачем мы это делаем

Цели: нативный CLI без обязательного Python, потенциальное ускорение отдельных
этапов компиляции, контроль потребления памяти и будущая интеграция с системными
интерфейсами. Rust сам по себе НЕ гарантирует более быстрый сгенерированный
JavaScript или Kotlin. Выигрыш необходимо измерять на равных данных.

## Что реализовано в Rust

Каталог rust/sedrava-core содержит самостоятельную Rust-библиотеку и бинарник
sedrava-native. Это реальное выполнение подмножества .sdr, а не обёртка над
Python. На первой стадии поддерживаются:

- Чтение UTF-8 .sdr, ограничение размера исходника.
- Типы int32, bool, text; точный подсчёт Unicode scalar values, лимит 1024.
- Арифметика +, -, * с проверкой переполнения; сравнения и логические операции.
- Переменные состояния, derive, объявление persist (синтаксис, без хранения).
- Атомарные действия, присваивания, let, require, if/else.
- Правила rule и встроенные test.
- Проверка простого экрана screen main (без генерации GUI).
- Команды check, test, run, inspect; JSON-результат run.

**Не поддерживаются:** record/list/collections, pure functions, imports, Host
Effects, навигация, site/webapp, генераторы Web/Android, сохранение и миграции.
Неподдерживаемые конструкции отклоняются явно; тихого отката на Python нет.

## Как запустить

Нужны Rust/Cargo с компонентом rustfmt. В репозитории есть
rust/rust-toolchain.toml. Из корня проекта:

    cargo build --manifest-path rust/Cargo.toml
    cargo test --manifest-path rust/Cargo.toml --workspace --all-targets
    cargo fmt --manifest-path rust/Cargo.toml --all -- --check

После сборки:

    ./rust/target/debug/sedrava-native --version
    ./rust/target/debug/sedrava-native check examples/counter.sdr
    ./rust/target/debug/sedrava-native test examples/reference_09.sdr
    ./rust/target/debug/sedrava-native run examples/text_profile.sdr rename
    ./rust/target/debug/sedrava-native inspect tests/rust_cases/scalars.sdr

На Windows используйте rust\target\debug\sedrava-native.exe.

При наличии Python 3.10+ сравните с существующим компилятором:

    python3 scripts/verify_rust_core.py --random-cases 32

Скрипт сравнивает JSON-состояния и факт принятия/отказа для ограниченного набора
сценариев. Совпадение факта отказа не означает совпадения причины ошибки.
Для публикации результатов сохраняйте SHA, версии, команды и сырой вывод.

## Архитектура

- src/model.rs: типы, AST, ограничения и ошибки.
- src/expr.rs: лексер, разбор и вычисление выражений.
- src/parser.rs: декларации языка и проверка типов.
- src/runtime.rs: атомарные переходы состояния.
- src/main.rs: нативный CLI.
- src/lib.rs: публичный Rust API и конформанс-тесты.
- tests/rust_cases/: программы для проверки.
- scripts/verify_rust_core.py: дифференциальные сравнения с Python.

## Критерии переноса

1. Сборка и тесты Rust проходят в зафиксированном окружении.
2. Зафиксирован Cargo.lock, описаны ошибки и ограничения.
3. Есть сравнительные проверки реального поведения на общих примерах.
4. Неподдерживаемые возможности явно отклоняются.
5. В сравнении скорости всегда указано, что измерено.
6. Перед переключением основного CLI понадобятся тесты records/collections,
   modules, Host Effects, генераторов Web/Android.

**SedravaSQL** — отдельный проект. Будущая интеграция через API не должна
обходить проверки эффектов и прав.

См. [план решений](ADR_RUST_CORE.md) и [главный README](../README.md).

## Подтверждённые проверки (22 ноября 2026)

В тестовой среде Linux x86_64 / Rust 1.100.0 / Python 3.12.3:
Rust 14 unit tests PASS, 263 сравнения с Python без обнаруженных расхождений
для поддерживаемого скалярного подмножества, штатные 274 Python-теста
PASS (5 пропущено). Подробности, команды, версия кода и ограничения —
в [отчёте с исходными измерениями](../evidence/rust-core/README.md).

В сравнении коротких CLI-команд Rust показал медианное время примерно
в 50–64 раза меньше Python. **Это преимущество запуска и выполнения
конкретных коротких команд, а не доказанное ускорение всех программ Sedrava.**
