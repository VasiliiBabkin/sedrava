## Scope and known limits

The new native Site mode supports only simple page metadata, basic layout elements, text, links, escaped static HTML and multi-page directory output. Unsupported directives are rejected.

Still **not migrated**: full Site/WebApp grammars, component expansion, responsive styles/assets/images, real-browser acceptance of full WebApp, full Android Compose support and APK/device tests, HTTP/Host APIs, stable IR/spans, Windows/macOS binary distribution, full language conformance and crash/concurrency/fuzz verification.
