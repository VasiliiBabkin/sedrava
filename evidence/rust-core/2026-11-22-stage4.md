# Rust migration issue #65 — native modules, scalar Web and distribution preparation

**Date:** 2026-11-22. **Status:** experimental milestone. Full language migration
is NOT complete; stable Python compiler and installed PyPI entry point unchanged.

## Added

- Bounded local-only import expansion on Rust for functions/record declarations
  (import depth 16, max 32 imported module paths, no network, symlinks or
  parent traversal). Component/style macros and complete Site/WebApp modes
  are not implemented in native Rust.
- Typed Widget AST added to the Rust app model.
- Native command build web FILE --output PATH for explicitly restricted
  **single-screen scalar programs without persist, records/lists, pure
  functions or navigation**. JS/HTML is generated in Rust, not through Python.
- Node.js smoke test of generated Web UI: buttons, derived state, invariant
  rejection, int input, show/hide and safe text output. This is a DOM mock,
  NOT real-browser acceptance or browser security certification.
- Rust native package can be installed from source with Cargo.
  Separate preview-archive tool creates TAR.GZ or ZIP with LICENSE, SHA256SUMS,
  manifest and explicit incomplete-product warnings.
- Russian documentation on binaries/installation and native Web limitations.
