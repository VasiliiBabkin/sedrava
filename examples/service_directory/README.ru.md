# Сервисный справочник A33

Декларативный пример с заказчиками, объектами и оборудованием. Одна схема domain.sdr, manifest format 2. Требуется компилятор A33 из этой ветки, не опубликованный alpha.3.

[Контракт и команды запуска](../../docs/DOMAIN_MODEL_A33.ru.md). Для базы используйте новый приватный каталог. Сервер только loopback; новый формат не переносит данные старого приложения. Списки и создание, выбор связей; обновление вручную, заявки и история пока в отдельном примере service_desk. Не использовать ценные данные.
